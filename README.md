# 📊 Student Placement Prediction System
## Project Overview
This project predicts a student's placement chances based on academic and skill-related parameters.

The system evaluates:
- CGPA
- Internships
- Communication Skills
- Projects Completed

and provides a placement prediction with probability percentage.
